在前辈代码基础上修改的 Bangumi（bgm.tv）美化脚本，支持油猴（Tampermonkey）和 Bangumi 自带的超合金组件。

仓库：[sqb2020/bangumi-beautify](https://github.com/sqb2020/bangumi-beautify)

## ① 自定义背景与毛玻璃 `bangumi_bg_custom.user.js`

> 把老婆的照片设成全站背景，调透明度做出毛玻璃效果。

基于 [rabbitohh/bangumi-css](https://github.com/rabbitohh/bangumi-css) 改造。

| 配置面板 | 渐变背景 + 毛玻璃 |

### 功能

- 🎨 **四种背景模式**：纯色 / 渐变 / 图片 URL / 随机图片（[栗次元 API](https://t.alcy.cc)，17 个分类，刷新自动换图，含历史记录）
- 🎚️ **总不透明度**：0~3 可调，控制整体玻璃浓淡
- 🪟 **头部玻璃浓度**：顶栏/导航玻璃单独可调，默认跟随总不透明度
- 🌙 **深色模式**：自动 / 亮色 / 暗色 三档；「自动」跟随站点右下角「关灯」开关与系统偏好，互不抢设置
- 🧊 **全站玻璃统一**：首页、条目、小组、时间线、相册等所有区域同一套玻璃参数（底色 / 模糊 / 饱和），深浅两色各自成体系

### 使用

```
安装后访问任意 bgm.tv 页面 → 右下角 ⚙ 按钮 → 选模式调参数 → 点「应用」
```

## ② 每日放送 · 时间轴（No API）`bangumi_calendar_timeline_no_api.user.js`

> 把日历页从密集网格变成按天分列的时间轴，不调 API，打开立刻显示。

![时间轴 No API](https://p.sda1.dev/34/b722ad87f8a6a2d1b4426da1dc9015e6/每日放送时间轴no-api.png)

- 📊 一周七天等宽分列，卡片显示封面 + 番名 + 原名
- 🟠 今天列高亮；⬅️➡️ 上周 / 今天 / 下周导航
- 🖱️ 点击条目跳转番剧主页；⚡ 纯 DOM 提取，零等待
- 想改封面大小：搜索 `.bct-ep img` 调整 `width/height`（默认 64×80，约 4:5 最佳）

## ③ 每日放送 · 时间轴（完整版）`bangumi_calendar_timeline.user.js`

> 功能最完整的时间轴，调 API 获取集数与每集标题。

![时间轴 完整版](https://p.sda1.dev/34/1a67302b4ba346e1583ff73c6623fbe7/每日放送时间轴.png)

- 包含 ② 的全部功能，另显示「第 N 话」+ 集标题，今日未播标注「待播出」
- 🔄 渐进式加载：骨架先渲染，集数信息逐个填充

| | ② No API | ③ 完整版 |
|---|---|---|
| 集数和标题 | ❌ | ✅ |
| 需要 API 权限 | ❌ | ✅ |
| 超合金组件 | ✅ | ❌ |
| 加载速度 | 即时 | 需拉取 API（几秒） |

## ④ 首页节目按星期分组 `bangumi_week_blocks.user.js`

> 把首页「我的 Bangumi」追番列表按星期分成七块卡片，今天高亮。

![首页星期分组](https://p.sda1.dev/34/f3dc8380cc4962ef8b5787fc47e31d56/首页节目按星期分组.png)

- 🎯 周一~周日各一块，单列排列，超期条目归入「完结」
- 🟧 今天高亮；✨ 纯 DOM 修补，不调 API

## 🔧 安装方法

**油猴（Tampermonkey）**：安装扩展 → 新建脚本 → 粘贴 `.user.js` 内容 → `Ctrl+S` 保存。

**超合金组件**：https://bgm.tv/dev/app → 「添加新组件」→ 粘贴脚本内容（①②④ 支持，③ 因需 API 权限仅油猴）。
